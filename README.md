## 阅读方法

1. 初学先读第 1—4 章，再了解第 5—8 章的任务和应用；进入综合模块后学习推理、算法原理与应用方案。
2. 结合每个知识点的「考纲要求」阅读原文选读、编者讲解及对应例题。重点加粗用于辅助定位，不能替代完整理解。
3. 对掌握级知识点自行手算或解释代码流程，再核对解析与自测。遇到疑问，可通过节末编号查阅原始来源。
4. 下载后可在支持书签的 PDF 阅读器中导航。GitHub 的内嵌预览不一定支持 `#page=` 跳页，完整页码同时保留在[知识点导航](./docs/OUTLINE.md)中。
